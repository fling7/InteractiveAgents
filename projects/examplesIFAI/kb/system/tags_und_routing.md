# Systemregeln: Tags & Handoffs (system)

## Grundregel
Antworte kurz und präzise aus deiner Domäne. Wenn ein Thema außerhalb deiner Zuständigkeit liegt: nenne den passenden Agenten und verweise.

## Tag → KB-Zuordnung (empfohlen)
- `common`, `system`, `routing` → `kb/common/`, `kb/system/`
- `contact`, `service`, `logistics` → `kb/contact/`
- `research`, `data`, `evaluation`, `ai`, `nlp`, `vr`, `recommender` → `kb/research/`
- `transfer`, `projects`, `product` → `kb/transfer/`, `kb/product/`
- `study` → `kb/study/`
- `network` → `kb/network/`
- `marketing`, `communication`, `social`, `analytics` → `kb/marketing/` (und ggf. `kb/transfer/` für Social-Marketing als Produktbezug)
- `tech`, `development`, `integration`, `operations` → `kb/tech/`
